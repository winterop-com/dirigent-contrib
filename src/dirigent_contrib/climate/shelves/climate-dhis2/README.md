# The open climate service with DHIS2

Documents that carry what the open climate service makes into DHIS2 through the
`dhis2.*` blocks of `dirigent-dhis2`, which an instance installs beside this pack.

| File | The operation |
| --- | --- |
| [climate-sync-to-dhis2.yaml](climate-sync-to-dhis2.yaml) | Sync a climate dataset, aggregate it to org units, and import it into DHIS2. |
