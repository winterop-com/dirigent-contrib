# Chap with DHIS2

Documents that carry what Chap decides into DHIS2 through the `dhis2.*` blocks of
`dirigent-dhis2`, which an instance installs beside this pack.

| File | The operation |
| --- | --- |
| [chap-predict-alert-review-import.yaml](chap-predict-alert-review-import.yaml) | Forecast, record the alerts it breaches, wait for their review in Chap, and message each district with an approved one. |
